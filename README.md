# Tic Tac Toe

A classic Tic Tac Toe game built using HTML, CSS, and Vanilla JavaScript.

## Features

- **Interactive UI**: Playable 3x3 grid with hover effects for an intuitive experience.
- **Score Tracking**: Automatically keeps track of the score for both "X" and "O" across rounds.
- **Victory & Tie Detection**: Highlights when a player wins or if the game ends in a tie.
- **Reset Functionality**: Includes a "New Game" button to easily clear the board and start a fresh round while keeping the score intact.
- **Retro Font**: Styled with the "Press Start 2P" font for a classic arcade feel.

## Play

Simply open `index.html` in your web browser to start playing!
